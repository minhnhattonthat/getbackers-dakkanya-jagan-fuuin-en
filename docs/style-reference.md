# Style reference - GetBackers Dakkanya: Jagan Fuuin!

Approved pilot (Act 1 opening, checked in-game). Match these voices.

## Voices
| Character | Japanese voice | English voice |
|---|---|---|
| Ban (蛮) | rough Tokyo slang (ねェ, ンな, 俺様), cocky, crude, secretly soft | swaggering, clipped, slangy ("Shaddap", "gonna", "why don'tcha"), mocks people, calls himself "the great Ban" for 俺様 when it is a boast |
| Ginji (銀次) | cheerful, childish (んあ~, ~だよね), calls Ban 蛮ちゃん | warm, naive, whiny when hungry; "Ban" (drop -chan), "Baaan..." when wailing |
| Anzu (杏) | perky reporter girl, ends sentences with ッス | upbeat; the ッス habit = a tag ", see!" / "see?" at the end of SOME lines (not every line) |
| Emishi (笑師) | Kansai comedian | relaxed, jokey ("ya", "ain't", "lemme tell ya") |
| Kazuki (花月) | polite, refined, 僕 | formal, gentle, precise |
| Shido (士度) | gruff, terse | blunt and short |
| Akabane (赤屍) | eerily polite です/ます, クス | courteous, unsettling ("Heh...") |
| Himiko (卑弥呼) | sharp, sassy | sharp, teasing |
| Kira (吉良) | fake Italian (ボンジョールノ, マンマ・ミーア) | keep the Italian words: "Buongiorno!", "Mamma mia!", "Ciao" |
| Maria (マリーア) | Spanish flair (ブエノスタルデス), flirty | keep "Buenas tardes!", playful |
| Hevn (ヘヴン) | bossy business-like | brisk, bossy |
